Things to Notice
Waveforms

(The sound is not synchronized to the visuals, the wave on the string travels much slower than it would in real life to produce such a tone.) Try "plucking" the string in the middle. Notice that there are only odd harmonics present, the first, the third, etc. The sound is pleasant, clear Now try "plucking" near the end of the string. Notice that now all harmonics are present, and they have larger amplitudes than in the previous case. The sound now is way harsher.

Ratios

Try "plucking" the string one-third of the way from one end. To find that position, you can use an interesting trick. Imagine that the string is hit with a hammer instead of being plucked at that position (it is easier to think about it this way, but both methods generate the same harmonics, hitting lifts the string). If we are exactly at the right position, the third harmonic should not be present, because the hammer hit exactly where that harmonic has a node, so it was not excited. But the sixth, ninth, etc. harmonics also have a node there, and so they are not excited either. This works with any harmonic, you can find where the fourth, eighth, etc. or the fifth, tenth, etc. are not excited.
